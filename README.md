# Omniverse Compute ($OMC) Official Website

Official website for **Omniverse Compute** — The Next-Gen Decentralized GPU Compute Network on BNB Chain.

## Live Site
(After deploying with GitHub Pages)

## Structure
- `index.html` — Main website
- `assets/` — Whitepaper PDFs

## How to deploy with GitHub Pages
1. Upload this repository
2. Go to Settings → Pages
3. Select `main` branch and root (or `/docs`)
4. Save

## Whitepapers
Place the following files in the `assets` folder:
- Omniverse Compute (OMC) Whitepaper Deck.pdf
- Omniverse Compute (OMC) Whitepaper - English Version.pdf
